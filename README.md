<h1 align="center">Small tools for macOS</h1>

<p align="center">Focused apps for captions, dictation, file organization, and clipboard history.</p>

## Apps

- [CaptionGrab](https://github.com/9phfr6dsw4-dotcom/captiongrab) — Get YouTube captions and export transcripts as Markdown or Word.
- [EchoType](https://github.com/9phfr6dsw4-dotcom/echotype) — Private, on-device dictation for macOS.
- [Quick Drop Zone](https://github.com/9phfr6dsw4-dotcom/quick-drop-zone) — Review and organize files from the menu bar.
- [Clipboard Shelf](https://github.com/9phfr6dsw4-dotcom/clipboard-shelf) — Searchable menu-bar clipboard history.
